# MWM Smart HR — نسخة محلية مترابطة

هذه النسخة تجمع صفحات المشروع في تطبيق واحد، مع الحفاظ على تصميم الصفحات الأصلية قدر الإمكان وإضافة الصفحات الناقصة المطلوبة لسير التوظيف.

## التشغيل

1. فك ضغط المجلد `MWM` في مكان مناسب.
2. تأكد من وجود Python 3.9 أو أحدث.
3. شغّل `start.py` بالنقر المزدوج عليه أو من الطرفية:

   ```bash
   python start.py
   ```

4. ستفتح صفحة تسجيل الدخول تلقائيًا. أدخل بريدًا وكلمة مرور غير فارغين لاستخدام النسخة التجريبية، أو أنشئ ملف عرض جديدًا من زر إنشاء حساب.
5. لفتح التطبيق يدويًا استخدم `http://127.0.0.1:8000`.

لا تفتح `index.html` مباشرة من القرص؛ يجب تشغيل الخادم حتى تستطيع الصفحات تحميل بعضها بواسطة `fetch`.

## الأقسام المتصلة

- **لوحة التحكم:** ملخص المناصب والمرشحين وروابط مباشرة لمسار التوظيف.
- **المناصب الوظيفية:** إضافة المنصب وتعديله وعرضه وحذفه، مع إحصاءات وفلاتر.
- **بطاقة الوظيفة:** تحفظ المعلومات الأساسية وتشاركها مع صفحات المتطلبات والمخاطر والقرار.
- **متطلبات شاغل الوظيفة:** حفظ المؤهلات والخبرة والمهارات والكفاءات والمتطلبات الخاصة.
- **مخاطر الوظيفة وظروفها:** حفظ ظروف العمل وسجل المخاطر وإجراءات الوقاية.
- **إدارة المرشحين:** إضافة ملفات المرشحين وربط كل ملف بمنصب محدد.
- **المطابقة الذكية:** ترتيب المرشحين بناءً على أوزان التقييم القابلة للتعديل.
- **معايير المطابقة والتقييم:** الأوزان الأربعة يجب أن يكون مجموعها 100%.
- **اتخاذ القرار:** اختيار قبول المرشح أو طلب مقابلة إضافية أو رفضه، مع حفظ ملاحظات المدير.
- **التقارير والنتائج:** ملخص الحالات وسجل القرارات وتصدير المرشحين بصيغة CSV.
- **الإعدادات:** بيانات مساحة العمل وتصدير/استيراد نسخة احتياطية بصيغة JSON.

## حفظ البيانات وحدود هذه النسخة

تُحفظ بيانات المناصب والمرشحين والمتطلبات والمخاطر والأوزان والقرارات في `localStorage` داخل المتصفح الحالي، وتنتقل التعديلات بين الأقسام تلقائيًا. استخدم النسخة الاحتياطية من صفحة الإعدادات إذا رغبت في نقل البيانات يدويًا.

تسجيل الدخول هنا واجهة تجريبية محلية فقط؛ لا يوجد خادم قاعدة بيانات أو مصادقة آمنة أو مزامنة بين أجهزة متعددة. لا تستخدم هذه النسخة لحفظ كلمات المرور أو البيانات الشخصية الحساسة أو لتشغيل إنتاجي قبل إضافة backend ومصادقة حقيقية.

## الملفات الأساسية

- `index.html`: الهيكل العام والشريط الجانبي وشريط الأعلى.
- `app.js`: التوجيه، التخزين، الربط بين الصفحات، النماذج والتقارير.
- ملفات HTML الأخرى: واجهات الأقسام.
- `start.py`: خادم محلي بسيط لا يحتاج إلى تثبيت مكتبات إضافية.

## مساحة المترشّح الجديدة

توجد بوابة المترشّح في `candidate-login.html`، وتفتح بعد تسجيل الدخول في `candidate-portal.html`. ويمكن الوصول إليها من رابط «ادخل إلى مساحة المترشّح» أسفل صفحة دخول إدارة الموارد البشرية.

تتضمن البوابة:

- إنشاء حساب مترشّح وتسجيل الدخول وتغيير البريد أو كلمة المرور من إعدادات الحساب.
- لوحة شخصية بملخص الطلبات والفرص المفتوحة وآخر الحالات.
- استعراض الوظائف التي حالتها «شاغر» أو «قيد التوظيف»، والبحث والتصفية حسب المصلحة وعرض تفاصيل ومتطلبات كل منصب.
- إرسال طلب ترشح واحد لكل منصب، ومتابعة الحالة، وسحب الطلب قبل انتقاله إلى مرحلة المقابلة.
- ملف مهني يتضمن الاسم، وبيانات الاتصال، والمؤهل، والتخصص، والخبرة، والمهارات، والنبذة، وصورة اختيارية، وسيرة ذاتية PDF أو Word.
- مشاركة طلبات المترشحين الجدد مع قسم «إدارة المرشحين» في واجهة المدير. ويمكن للمدير تحديث الحالة، وتظهر الحالة الجديدة للمترشح عند تحديث البوابة. يظهر زر تنزيل السيرة الذاتية في قائمة المرشحين عند إرفاقها.

### حدود الأمان والتشغيل

هذه بوابة نموذج أولي محلي: بيانات الحساب والملف تُحفظ في `localStorage`، والجلسة في `sessionStorage`، وكلمة المرور محفوظة كبصمة SHA-256 داخل المتصفح. هذا لا يعادل مصادقة خادمية آمنة، ولا يوجد تحقق من البريد، أو استرجاع كلمة مرور عبر البريد، أو مزامنة بين الأجهزة، أو صلاحيات خادمية. كما أن طلبات المترشحين الجديدة تُضاف إلى سجل المرشحين المحلي المشترك، لذلك لا تستخدم النسخة لحفظ بيانات توظيف حقيقية قبل ربطها بقاعدة بيانات وخادم ومصادقة وصلاحيات ونسخ احتياطي مناسبين.

للتجربة من البداية: شغّل `python start.py`، ثم افتح `http://127.0.0.1:8000/candidate-login.html` لإنشاء حساب مترشّح. افتح في نافذة أخرى `http://127.0.0.1:8000/login.html` للدخول إلى مساحة المدير، ثم قسم إدارة المرشحين لمراجعة الطلب الذي أرسلته وتحديث حالته. يجب أن يكون الموقعان في نفس المتصفح ونفس العنوان المحلي حتى يشتركا في مخزن البيانات.
